# Privacy policy

Simple Video Redactor processes videos locally. It has no accounts, analytics, telemetry, advertising, or footage uploads. Input files are read locally; previews and thumbnails use temporary local files. A crash can leave temporary files behind. Export files are saved to the location selected by the user.

The source launcher downloads Python dependencies from PyPI on first setup. PyPI's [privacy policy](https://policies.python.org/pypi.org/Privacy-Notice/) applies to that connection. The optional donation button opens Buy Me a Coffee, whose [privacy policy](https://www.buymeacoffee.com/privacy-policy) applies to its website. GitHub support links open GitHub, whose [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) applies there. Do not attach private footage to public support issues.

Contact the maintainer using [GitHub issues](https://github.com/B1GM4NT1NGS/Simple-Video-Redactor/issues).
